# 能力全景与路线图

> 这是「版本记录 · Markdown 对话主题排版」插件的能力全景。已交付 = 当前可用；路线图 = 待迭代实现。技术细节见 `docs/architecture.md` / `docs/themes.md` / `docs/variables.md`。

## A. 版本记录

| # | 能力 | 状态 |
| --- | --- | --- |
| A1 | 每次迭代自动形成不可变版本（Package），随时可回滚到任意历史版本 | ✅ |
| A2 | 版本台账：版本号、名称、日期、变更日志、主题名，按 packageId 去重 | ✅ |
| A3 | run 卡片内版本面板：当前版本徽标 + 本次变更日志 + 历史版本列表 | ✅ |
| A4 | `manifest/versions.json` 持久台账 + git tag 基线 | ✅ |
| A5 | 台账落盘到工作区文件自动同步（Host 用 fs 服务写 `manifest/versions.json`） | 🔜 |
| A6 | 版本对比视图（任意两版 diff 变更日志 / 配色差异） | 🔜 |

## B. 主题（颜色层）

| # | 能力 | 状态 |
| --- | --- | --- |
| B1 | 全局 token 覆盖：13 个 `--dsw-alias-*` token，浅/深双套 | ✅ |
| B2 | 叠加层机制：不改基线主题，卸载即还原，同一 source 更新即整层替换（原子切换） | ✅ |
| B3 | 主题文件化：每主题一个独立 CSS 文件（`plugin/assets/themes/*.css`），文件即主题；**内置主题 4 个**——`strawberry-mocha`（标准参考实现）+ 钛影 / 高清晰 / 墨黛，同一变量契约 100% 对齐（仅配色不同） | ✅ |
| B4 | 设置页「主题设置」选择模型：「系统自带」默认（零干预）+ 内置/用户主题互斥单选 | ✅ |
| B5 | 外观 ☀️/🌙/🖥️ 三档对任意选中主题可用（主题自带浅深两档即跟随切换，偏好持久化） | ✅ |
| B6 | 用户主题动态加载：`$HOME/.dsh/web-themes/` 放 CSS 文件即新主题（无需打包/升级插件），目录动态解析，设置页一键刷新 | ✅ |
| B7 | 用户主题管理：🆕 新建（默认模板 = 内置 `strawberry-mocha` 内容，失败回退 `template.css`）+ ✏️ 编辑（实时语法高亮 / 格式化 / 保存，事务化分块上传 + 双端 CSS 校验）；内置主题只读 | ✅ |
| B8 | 资产文件化：内置主题 / 面板样式 / 参考模板由 Host 运行时从文件读取，改文件刷新即生效 | ✅ |
| B9 | 统一变量契约：L0 平台 token（13）→ L1 身份色（核心 17 + 扩展 + `--hl-*` 语法高亮）→ L2 排版/形状常量 + L3 旋钮，见 `docs/variables.md` | ✅ |
| B10 | 选择持久化（刷新/重启后保持所选主题；当前为会话级内存态，恢复默认「系统自带」） | 🔜 |

## C. Markdown 排版
