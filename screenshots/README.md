# screenshots/ —— 主题预览图

README 主题画廊引用的图片放这里（GitHub 惯例：仓库根 `screenshots/`）。

## 需要的内容

4 张内置主题预览图（每主题 1 张，建议浅色档、对话视图、能看出排版与配色的差异），文件名固定：

| 文件 | 主题 |
| --- | --- |
| `strawberry-mocha.jpg` | 草莓猛男粉（标准参考） |
| `cyber-titanium.jpg` | Cyber Titanium · 钛影 |
| `high-vis-clarity.jpg` | High-Vis Clarity · 高清晰 |
| `pine-smoke-ink.jpg` | 松烟墨黛 |

## 建议

- 尺寸 ≥ 1200px 宽、PNG；同一批截图尽量用同一个对话页面（素材一致才方便对比）
- 生成后 `git add screenshots/*.jpg` 提交，README 画廊自动生效
- 若想展示深色档，文件名加 `-dark` 后缀即可（如 `strawberry-mocha-dark.jpg`），README 里再补一行
